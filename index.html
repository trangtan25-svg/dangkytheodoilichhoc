Cấu hình Web App URL từ Apps Script (Code.gs)

Sau khi tạo Web App trên Google Apps Script, dán URL vào đây để kết nối tức thì với Google Sheet 1bv1twT1xlmRYWbEI3uzlEV-te5-pbtm5qIw7cqJa6HA!

Hướng dẫn Kết nối Google Sheet 2 Chiều

Liên kết trực tiếp với Google Sheet ID: 1bv1twT1xlmRYWbEI3uzlEV-te5-pbtm5qIw7cqJa6HA

1

Mở Google Sheet Target

Mở file Google Sheet của bạn tại địa chỉ:

https://docs.google.com/spreadsheets/d/1bv1twT1xlmRYWbEI3uzlEV-te5-pbtm5qIw7cqJa6HA/edit
2

Tạo Apps Script Webhook 2 chiều

Vào menu Tiện ích mở rộng (Extensions) → Apps Script. Dán mã nguồn từ file google-apps-script.js vào và lưu lại.

Bấm Triển khai (Deploy) → Thực thi dưới dạng Web App. Thiết lập quyền truy cập: "Bất kỳ ai" (Anyone).

3

Cấu hình Environment Variables trên Vercel

Khi Deploy dự án này lên Vercel, hãy vào mục Settings → Environment Variables và thêm biến môi trường sau:

GOOGLE_SHEET_ID=1bv1twT1xlmRYWbEI3uzlEV-te5-pbtm5qIw7cqJa6HA
GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/AKfycbxYOUR_SCRIPT_ID/exec
